# Issue Tracker - Laravel

This is a web application built with Laravel for managing and tracking issues (bug tracking / task management system).

##  Features

- User authentication (Login / Register)
- Create, edit, and delete issues
- Issue status management (Open / In Progress / Closed)
- Dashboard for managing issues
- MySQL database integration
- MVC architecture (Laravel framework)

##  Technologies Used

- Laravel 12
- PHP 8+
- MySQL
- HTML, CSS, Bootstrap
